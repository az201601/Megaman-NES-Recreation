# Project credits

## Weapon-menu icon artwork

**KindlyPatrick** — source weapon-icon sheet supplied by the user, bearing “BY KINDLYPATRICK”.

The seven adapted weapon/tool menu icons are credited as:

> Weapon-menu icons adapted from artwork by KindlyPatrick.

Adaptations retain the source designs, remap their colours to the original MM5 unselected palette and use the original MM5 menu casing. The unmodified reference sheet is preserved in `Assets/Mega Man/MM5/Pause Menu/Weapon Icon References/`.

This attribution is recorded for eventual in-game credits; a credits screen has not yet been implemented. No licensing terms accompanied the supplied sheet. Attribution is not a substitute for checking redistribution permission before release.
