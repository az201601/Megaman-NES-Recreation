Mega Man animation frames, extracted from the ROM.
Canvas 48x48; set the GameMaker sprite origin to (24,24).
L = facing left, R = facing right. *_strip.png = frames side by side.
Consecutive duplicate frames were collapsed; 'delay' is the ROM's
frame count per animation step (use it for image_speed: 60/delay/60).
Folder P = default palette. Folders C,I,B,F,E,G,M contain the
weapon colour swaps for the core animations only.

stand        state=$00  frames=$01  delay=8 f/step
stand_shoot  state=$01  frames=$10  delay=8 f/step
rock         state=$02  frames=$09  delay=8 f/step
walk_start   state=$03  frames=$01,$02  delay=2 f/step
run          state=$06  frames=$03,$05,$04,$05  delay=6 f/step
run_shoot    state=$07  frames=$11,$13,$12,$13  delay=6 f/step
jump         state=$09  frames=$06  delay=0 f/step
jump_shoot   state=$0A  frames=$14  delay=0 f/step
land         state=$0F  frames=$04,$03  delay=1 f/step
